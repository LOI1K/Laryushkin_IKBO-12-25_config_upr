# Эмулятор командной оболочки UNIX

Практическая работа №1 по дисциплине
«Конфигурационное управление».

Группа: ИКБО-12-25
Вариант: 11

## Описание

Консольный эмулятор командной оболочки UNIX-подобной ОС.
Программа принимает команды пользователя, обрабатывает
аргументы и выводит результаты выполнения.

На первом этапе реализован прототип REPL.

## Функциональность

- `ls` — заглушка, выводит имя команды и аргументы.
- `cd` — заглушка, выводит имя команды и аргументы.
- `exit` — завершает работу эмулятора.
- Неизвестные команды вызывают сообщение об ошибке.
- Пустой ввод игнорируется.

## Настройки

Имя виртуальной файловой системы задаётся константой
`VFS_NAME` в файле `src/main.py`.

По умолчанию используется `my-vfs`.

## Запуск

Требуется Python 3.

```bash
./run.sh
```

Альтернативный способ:

```bash
python3 src/main.py
```

Дополнительная сборка не требуется.

## Тестирование

Запуск автоматических тестов:

```bash
python3 -m unittest discover -s tests -v
```

## Примеры использования

```text
my-vfs:/$ ls documents
Команда: ls
Аргументы: ['documents']

my-vfs:/$ cd home
Команда: cd
Аргументы: ['home']

my-vfs:/$ unknown
Ошибка: неизвестная команда 'unknown'

my-vfs:/$ exit
Выход из эмулятора.
```
