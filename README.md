## 1. Описание проекта

Эмулятор командной оболочки UNIX-подобной операционной системы, разработанный на языке Python.

Программа поддерживает интерактивный ввод команд (REPL), параметры командной строки, выполнение стартовых скриптов и загрузку виртуальной файловой системы (VFS) из директории на диске.

В рамках практической работы реализованы первые три этапа:

1. Разработка прототипа эмулятора (REPL).
2. Добавление конфигурации и стартовых скриптов.
3. Реализация загрузки виртуальной файловой системы.

Программа является консольным приложением и не требует дополнительных библиотек Python.

## 2. Реализованная функциональность

### Этап 1. REPL

Реализован интерактивный режим работы с командами.

Поддерживаемые команды:

- `ls` — заглушка, выводящая название команды и переданные аргументы.
- `cd` — заглушка, выводящая название команды и переданные аргументы.
- `exit` — завершение работы эмулятора без аргументов.

Дополнительно реализованы:

- Разделение пользовательского ввода по пробельным символам.
- Обработка пустых строк.
- Вывод сообщения при вводе неизвестной команды.
- Проверка отсутствия аргументов у команды `exit`.
- Отображение приглашения командной строки с названием VFS.

Команды `ls` и `cd` на данном этапе не изменяют состояние файловой системы.

### Этап 2. Конфигурация

Реализована обработка параметров командной строки с помощью библиотеки `argparse`.

Поддерживаемые параметры:

- `--vfs` — путь к директории виртуальной файловой системы.
- `--script` — путь к стартовому скрипту.

При запуске программа выводит значения переданных параметров.

Стартовый скрипт представляет собой текстовый файл с последовательностью команд, выполняемых эмулятором.

Реализованы:

- Последовательное выполнение команд из стартового скрипта.
- Отображение выполняемых команд и результатов.
- Пропуск пустых строк и строк комментариев, начинающихся с `#`.
- Продолжение выполнения после неизвестных команд и некорректного вызова `exit`.
- Завершение выполнения при корректной команде `exit`.
- Вывод сообщения об ошибке при невозможности прочитать стартовый скрипт.

Если стартовый скрипт завершился без команды `exit`, программа переходит в интерактивный режим.

### Этап 3. Виртуальная файловая система (VFS)

Реализована загрузка виртуальной файловой системы из обычной директории на диске.

Для работы с VFS используется класс `VirtualFileSystem`, расположенный в файле `src/vfs.py`.

Возможности:

- Рекурсивная загрузка файлов и директорий.
- Хранение структуры виртуальной файловой системы в оперативной памяти.
- Поддержка вложенных директорий.
- Чтение текстовых и двоичных файлов.
- Сохранение содержимого файлов в виде байтов.
- Определение названия VFS по имени исходной директории.
- Подсчёт количества файлов и директорий.
- Обработка ошибок при указании несуществующей директории.
- Пропуск символических ссылок.
- Сохранение исходных файлов на диске без изменений.

Для хранения структуры используются:

- `set` — множество виртуальных путей директорий.
- `dict` — словарь, содержащий виртуальные пути файлов и их содержимое в байтах.

Корневая директория VFS обозначается символом `/` и учитывается при подсчёте директорий.

На данном этапе реализована загрузка данных в оперативную память. Полноценные операции навигации по VFS с помощью `ls` и `cd` относятся к четвёртому этапу и не входят в текущий объём работы.

## 3. Требования для запуска

Для работы программы необходимы:

- Python 3.
- Терминал macOS или Linux.
- Bash для запуска вспомогательных скриптов.

Установка дополнительных библиотек не требуется. Сборка проекта также не требуется.

Все приведённые ниже команды выполняются из корневой директории репозитория.

## 4. Запуск программы

### Обычный запуск

```bash
./run.sh
```

Альтернативный запуск через Python:

```bash
python3 -m src.main
```

### Запуск с виртуальной файловой системой

```bash
./run.sh --vfs vfs_examples/minimal
```

### Запуск со стартовым скриптом

```bash
./run.sh --script scripts/demo.txt
```

### Запуск с VFS и стартовым скриптом

```bash
./run.sh --vfs vfs_examples/minimal --script scripts/demo.txt
```

### Просмотр доступных параметров

```bash
./run.sh --help
```

## 5. Примеры виртуальных файловых систем

Для проверки третьего этапа подготовлены три варианта VFS.

### 5.1. Минимальная файловая система

Путь:

`vfs_examples/minimal`

Содержит один файл `hello.txt`.

Запуск:

```bash
./run.sh --vfs vfs_examples/minimal
```

Ожидаемое количество объектов:

- Директории: 1 (корневая).
- Файлы: 1.

### 5.2. Файловая система с несколькими файлами

Путь:

`vfs_examples/files`

Содержит три файла: `first.txt`, `second.txt`, `third.txt`.

Запуск:

```bash
./run.sh --vfs vfs_examples/files
```

Ожидаемое количество объектов:

- Директории: 1 (корневая).
- Файлы: 3.

### 5.3. Файловая система с вложенными директориями

Путь:

`vfs_examples/nested`

Содержит три уровня вложенных директорий и файл `deep.txt`.

Запуск:

```bash
./run.sh --vfs vfs_examples/nested
```

Ожидаемое количество объектов:

- Директории: 4 (включая корневую).
- Файлы: 1.

## 6. Демонстрационные сценарии

### Проверка второго этапа

Для проверки параметров запуска используются Bash-скрипты:

```bash
bash scripts/test_vfs.sh
bash scripts/test_script.sh
bash scripts/test_both.sh
```

Они проверяют запуск программы с параметром `--vfs`, со стартовым скриптом и с обоими параметрами одновременно.

Стартовый файл `scripts/demo.txt` содержит команды для демонстрации работы REPL и обработки ошибок.

### Проверка третьего этапа

Для проверки загрузки разных VFS используются следующие скрипты:

```bash
bash scripts/test_vfs_minimal.sh
bash scripts/test_vfs_files.sh
bash scripts/test_vfs_nested.sh
```

Каждый скрипт запускает эмулятор с соответствующей виртуальной файловой системой и выполняет команды из `scripts/stage3.txt`.

Сценарии позволяют проверить:

- Загрузку различных файловых структур.
- Выполнение команд `ls` и `cd` в режиме заглушек.
- Обработку неизвестных команд.
- Обработку некорректных аргументов команды `exit`.
- Корректное завершение работы эмулятора.

## 7. Пример работы программы

Пример интерактивного ввода без указания директории VFS:

```text
my-vfs:/$ ls documents
Команда: ls
Аргументы: ['documents']

my-vfs:/$ cd home
Команда: cd
Аргументы: ['home']

my-vfs:/$ unknown
Ошибка: неизвестная команда 'unknown'

my-vfs:/$ exit 123
Ошибка: exit не принимает аргументы.

my-vfs:/$ exit
Выход из эмулятора.
```

При передаче параметра `--vfs` в приглашении командной строки отображается имя соответствующей директории.

## 8. Автоматическое тестирование

Для тестирования используется стандартная библиотека Python `unittest`.

Всего реализовано **14 автоматических тестов**:

- 9 тестов проверки REPL, обработки команд, параметров запуска и стартовых скриптов.
- 5 тестов проверки виртуальной файловой системы.

Тесты VFS проверяют загрузку минимальной файловой системы, вложенные директории, двоичные файлы, неизменность исходных данных и обработку несуществующей директории.

Запуск всех тестов:

```bash
python3 -m unittest discover -s tests -v
```

При успешном выполнении тестов выводится:

```text
Ran 14 tests

OK
```
