# Эмулятор командной оболочки UNIX

Практическая работа №1 по дисциплине
«Конфигурационное управление».

Группа: ИКБО-12-25
Вариант: 11

## Описание

Консольный эмулятор командной оболочки UNIX-подобной ОС,
разработанный на Python.

Программа поддерживает интерактивный ввод команд (REPL),
параметры командной строки и выполнение стартовых скриптов.

## Реализованная функциональность

### Этап 1. REPL

- `ls` — заглушка, выводящая имя команды и аргументы.
- `cd` — заглушка, выводящая имя команды и аргументы.
- `exit` — завершение работы эмулятора.
- Обработка неизвестных команд и неправильных аргументов.
- Разделение пользовательского ввода по пробелам.

### Этап 2. Конфигурация

- `--vfs` — путь к директории виртуальной файловой системы.
- `--script` — путь к стартовому скрипту.
- Отладочный вывод параметров при запуске.
- Последовательное выполнение команд из скрипта.
- Продолжение выполнения после ошибочных команд.
- Отображение команд и результатов выполнения.

Загрузка и обработка содержимого VFS будут реализованы
на третьем этапе.

## Запуск

Требуется Python 3.

Обычный запуск:

```bash
./run.sh
```

Запуск с параметрами:

```bash
./run.sh --vfs vfs_examples/minimal
```

```bash
./run.sh --script scripts/demo.txt
```

```bash
./run.sh --vfs vfs_examples/minimal --script scripts/demo.txt
```

Дополнительная сборка не требуется.

## Автоматические тесты

```bash
python3 -m unittest discover -s tests -v
```

## Проверка скриптов macOS

```bash
./scripts/test_vfs.sh
./scripts/test_script.sh
./scripts/test_both.sh
```

## Примеры использования

```text
my-vfs:/$ ls documents
Команда: ls
Аргументы: ['documents']

my-vfs:/$ cd home
Команда: cd
Аргументы: ['home']

my-vfs:/$ unknown
Ошибка: неизвестная команда 'unknown'

my-vfs:/$ exit
Выход из эмулятора.
```

## Структура проекта

- `src/` — исходный код эмулятора.
- `tests/` — автоматические тесты.
- `scripts/` — стартовый скрипт и скрипты macOS.
- `vfs_examples/` — примеры виртуальной файловой системы.
- `run.sh` — запуск программы.
- `.gitignore` — исключения Git.
- `README.md` — документация проекта.
