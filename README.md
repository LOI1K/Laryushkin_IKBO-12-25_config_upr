## 1. Описание проекта

Проект представляет собой консольный эмулятор командной оболочки UNIX-подобной операционной системы, написанный на языке Python.

Эмулятор поддерживает интерактивную работу с командами (REPL), параметры запуска, выполнение стартовых скриптов и виртуальную файловую систему (VFS), загружаемую из директории на диске.

Реализованы все пять этапов практической работы:

1. REPL — прототип командной оболочки.
2. Конфигурация — параметры запуска и стартовые скрипты.
3. VFS — загрузка виртуальной файловой системы в оперативную память.
4. Основные команды — `ls`, `cd`, `echo`, `head`, `who`.
5. Дополнительные команды — `chmod`, `help`.

Для работы используются только стандартные библиотеки Python.

## 2. Реализованные этапы

### Этап 1. REPL

Реализован интерактивный цикл ввода и выполнения команд.

Функциональность:

- Консольный интерфейс (CLI).
- Приглашение к вводу с именем VFS.
- Разделение введённой строки на команду и аргументы по пробелам.
- Первоначальные заглушки команд `ls` и `cd`.
- Команда `exit` для завершения работы.
- Обработка пустого ввода и неизвестных команд.
- Проверка недопустимых аргументов команды `exit`.

При запуске без загруженной VFS команды `ls` и `cd` сохраняют поведение заглушек.

### Этап 2. Конфигурация

Реализована обработка параметров командной строки с помощью `argparse`.

Поддерживаемые параметры:

- `--vfs` — путь к директории виртуальной файловой системы.
- `--script` — путь к текстовому файлу стартового скрипта.

При запуске эмулятор выводит значения переданных параметров.

Стартовый скрипт выполняет команды последовательно, отображая ввод и результат каждой команды.

Пустые строки и строки комментариев, начинающиеся с `#`, пропускаются. Ошибочные команды не останавливают выполнение скрипта. Корректная команда `exit` завершает работу эмулятора.

### Этап 3. Виртуальная файловая система

Источник VFS — обычная директория на диске пользователя.

Класс `VirtualFileSystem` из `src/vfs.py` рекурсивно загружает структуру файловой системы в оперативную память.

Для хранения используются:

- `set` — виртуальные пути директорий.
- `dict` — виртуальные пути файлов и их содержимое в байтах.
- `dict` — права доступа к виртуальным файлам и директориям.

Возможности:

- Загрузка вложенных директорий.
- Чтение текстовых и двоичных файлов.
- Пропуск символических ссылок.
- Подсчёт количества файлов и директорий.
- Обработка ошибок при загрузке VFS.
- Сохранение исходных файлов на диске без изменений.

Корневая директория VFS обозначается `/`.

### Этап 4. Основные команды

Реализованы команды:

| Команда                | Назначение                                |
| ---------------------- | ----------------------------------------- |
| `ls [путь]`            | Вывести содержимое виртуальной директории |
| `cd [путь]`            | Перейти в виртуальную директорию          |
| `echo [текст]`         | Вывести переданный текст                  |
| `head [-n число] файл` | Вывести первые строки виртуального файла  |
| `who`                  | Показать пользователя эмулятора           |

Команды `ls` и `cd` поддерживают абсолютные и относительные виртуальные пути, в том числе `.` и `..`.

Команда `head` по умолчанию выводит первые 10 строк файла. Для указания другого количества используется параметр `-n`.

Команда `who` показывает имя пользователя, под которым работает эмулятор, и условное обозначение сеанса `emulator`.

Для проверки реализован стартовый сценарий `scripts/stage4.txt`.

### Этап 5. Дополнительные команды

Реализованы две дополнительные команды.

**`chmod` — изменение прав доступа**

Синтаксис:

```bash
chmod режим путь
```

Поддерживаются восьмеричные режимы доступа, например `600`, `644`, `755`.

Команда изменяет права виртуальных файлов и директорий только в памяти, не изменяя соответствующие файлы на диске.

Права хранятся в словаре `permissions` класса `VirtualFileSystem`.

Реализация моделирует изменение прав доступа, но не обеспечивает полную проверку этих прав при выполнении остальных команд эмулятора.

**`help` — справка по командам**

Выводит список всех поддерживаемых команд и их краткие описания.

Для проверки реализован стартовый сценарий `scripts/stage5.txt`, включающий успешные вызовы и обработку ошибок.

## 5. Примеры использования команд

Запустим эмулятор:

```bash
./run.sh --vfs vfs_examples/nested
```

Пример работы:

```text
nested:/$ ls
level1
nested:/$ cd level1
nested:/level1$ ls
level2
nested:/level1$ cd level2
nested:/level1/level2$ cd level3
nested:/level1/level2/level3$ ls
deep.txt
nested:/level1/level2/level3$ head deep.txt
Deep file
nested:/level1/level2/level3$ echo Hello World
Hello World
nested:/level1/level2/level3$ chmod 600 deep.txt
nested:/level1/level2/level3$ cd /
nested:/$ exit
Выход из эмулятора.
```

Успешная команда `chmod` не выводит сообщение. Результат изменения виртуальных прав проверяется автоматическими тестами.

Для просмотра всех доступных команд внутри эмулятора необходимо ввести:

```text
help
```

## 6. Примеры VFS

В проекте предусмотрены три тестовые виртуальные файловые системы.

| Директория             | Количество директорий | Количество файлов |
| ---------------------- | --------------------: | ----------------: |
| `vfs_examples/minimal` |                     1 |                 1 |
| `vfs_examples/files`   |                     1 |                 3 |
| `vfs_examples/nested`  |                     4 |                 1 |

В количество директорий включается корневая директория `/`.

Вложенная VFS имеет структуру:

```text
nested/
└── level1/
    └── level2/
        └── level3/
            └── deep.txt
```

Эти примеры позволяют проверить загрузку минимальной VFS, нескольких файлов и трёх уровней вложенных директорий.
