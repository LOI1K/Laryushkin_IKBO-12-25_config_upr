# Эмулятор командной оболочки UNIX

Практическая работа №1 по дисциплине
«Конфигурационное управление».

Группа: ИКБО-12-25
Вариант: 11

## Описание

Консольный эмулятор командной оболочки UNIX-подобной ОС,
разработанный на Python.

Программа поддерживает интерактивный ввод команд (REPL),
параметры командной строки и выполнение стартовых скриптов.

Виртуальная файловая система загружается из директории
на диске и хранится в оперативной памяти.

## Реализованная функциональность

### Этап 1. REPL

- `ls` — заглушка, выводящая имя команды и аргументы.
- `cd` — заглушка, выводящая имя команды и аргументы.
- `exit` — завершение работы эмулятора.
- Обработка неизвестных команд и неправильных аргументов.
- Разделение пользовательского ввода по пробелам.

### Этап 2. Конфигурация

- `--vfs` — путь к директории виртуальной файловой системы.
- `--script` — путь к стартовому скрипту.
- Отладочный вывод параметров при запуске.
- Последовательное выполнение команд из скрипта.
- Продолжение выполнения после ошибочных команд.
- Отображение команд и результатов выполнения.

### Этап 3. Виртуальная файловая система (VFS)

Реализована загрузка виртуальной файловой системы
из директории на диске пользователя.

Возможности:

- Рекурсивная загрузка файлов и директорий.
- Хранение файловой структуры в оперативной памяти.
- Поддержка вложенных директорий.
- Поддержка текстовых и двоичных файлов.
- Определение названия VFS.
- Подсчёт количества файлов и директорий.
- Обработка ошибок при загрузке VFS.
- Сохранение исходных файлов без изменений.

Для реализации используется класс `VirtualFileSystem`
в файле `src/vfs.py`.

При запуске с параметром `--vfs` программа загружает
содержимое указанной директории в оперативную память.

#### Примеры VFS

В проекте подготовлены три варианта:

1. `minimal` — минимальная файловая система.
2. `files` — файловая система с тремя файлами.
3. `nested` — файловая система с вложенными директориями.

#### Запуск

Минимальная VFS:

```bash
./run.sh --vfs vfs_examples/minimal
```

VFS с несколькими файлами:

```bash
./run.sh --vfs vfs_examples/files
```

VFS с вложенными директориями:

```bash
./run.sh --vfs vfs_examples/nested
```

#### Демонстрационные скрипты

```bash
./scripts/test_vfs_minimal.sh
./scripts/test_vfs_files.sh
./scripts/test_vfs_nested.sh
```

Скрипты проверяют загрузку различных VFS,
выполнение команд и обработку ошибок.

#### Тестирование

Для запуска всех автоматических тестов:

```bash
python3 -m unittest discover -s tests -v
```

Всего реализовано 14 автоматических тестов,
из которых 5 проверяют виртуальную файловую систему.

Команды `ls` и `cd` пока работают как заглушки.
Полноценная работа с виртуальными файлами и директориями
будет реализована на четвёртом этапе.

## Запуск

Требуется Python 3.

Обычный запуск:

```bash
./run.sh
```

Запуск с параметрами:

```bash
./run.sh --vfs vfs_examples/minimal
```

```bash
./run.sh --script scripts/demo.txt
```

```bash
./run.sh --vfs vfs_examples/minimal --script scripts/demo.txt
```

Дополнительная сборка не требуется.

## Примеры использования

```text
my-vfs:/$ ls documents
Команда: ls
Аргументы: ['documents']

my-vfs:/$ cd home
Команда: cd
Аргументы: ['home']

my-vfs:/$ unknown
Ошибка: неизвестная команда 'unknown'

my-vfs:/$ exit
Выход из эмулятора.
```
